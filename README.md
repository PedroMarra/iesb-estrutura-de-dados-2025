# Estrutura de Dados

Atividades da disciplina **Estrutura de Dados** (IESB, 2025), feitas em Python com Jupyter Notebook.

| Notebook | Assunto |
|---|---|
| `1_lista_tarefas.ipynb` | Lista de tarefas com listas |
| `2_fila_mercado.ipynb` | Simulação de fila de mercado |
| `3_syst_desfazer.ipynb` | Sistema de "desfazer" com pilha |
| `atv3_pilhas_py.ipynb` | Pilhas |
| `atv4_listas_py.ipynb` | Listas |
| `ATV5filas.ipynb` | Filas |
| `lambda_py.ipynb` | Funções lambda |

## Como abrir
Abra direto no GitHub (ele mostra os notebooks) ou rode localmente:
```bash
pip install notebook
jupyter notebook
```
